      EDINET（法定開示）

      API キーは各自で取得する必要があります（無料）。キーはこの PC の資格情報ストアに保存され、ファイルには書き込まれません。

      API キー
      1. API キー発行ページでサインアップ（メールアドレス登録）
      2. CAPTCHA と確認コードの入力
      3. パスワード設定（12文字以上・英大小／数字／記号から3種以上）
      4. 多要素認証（MFA）: 電話番号を登録し、SMS または音声通話で確認
      5. 連絡先（所属・氏名・電話番号）を入力すると API キーが表示されます

      2年間利用がないキーは自動削除されます。取得したデータを利用する際は出典（EDINET）の明記が必要です。

      Gemini（AI 分析）

      AI 分析は手動実行のみです。送信するのは株価・テクニカル指標・EDINET の開示一覧だけで、需給データは送りません。

      API キー

      公式ドキュメントに無料枠の数値表はありません。AI Studio のレート制限ページで自分のアカウントの値を確認して入力してください。RPM・TPM・RPD のいずれかが 0 の間は AI 機能は無効です。

      上限は API キー単位ではなくプロジェクト単位です。同じプロジェクトを他のツールでも使っている場合、本ツールの残量表示より早く上限に達します。

      無料枠では、送信した内容が Google の製品改善に使われ、人間のレビュアーが読む場合があります。

      429（クォータ超過）の判定は自前の見積りです。誤って打ち切り扱いになった場合はここで解除できます。

      空売り残高の取得（karauri.net）

      相手サーバーに負荷をかけないよう、間隔を空けて1件ずつ取得します。

      この連絡先は karauri.net へのリクエストごとに User-Agent として送信されます。自動取得であることを名乗るためのもので、ブラウザの偽装はしません。

      データの出典と利用上の制限

      株価 — Yahoo! Finance（yfinance）
      非公式ライブラリによる取得です。個人の分析用途に限ってください。
      空売り残高 — karauri.net（元データは JPX 公表）
      合計値は本ツールが算出したもので、サイトの公表値ではありません。0.5% 未満のポジションは公表されません。
      貸借取引残高 — 日本証券金融
      私的利用の範囲を超える利用、第三者への提供は禁止されています。貸借銘柄のみが対象で、本ツールで取得を始めた日以降のデータしかありません。
      法定開示 — EDINET（金融庁）
      利用時は出典の明記が必要です。決算短信・業績修正（TDnet）は含まれません。

      取得したデータを再配布・公開しないでください。需給データ（空売り残高・貸借取引残高）は画面表示のみに使い、エクスポート・AI への送信・レポートには含めません。

      別の PC へ移すときは data フォルダをまるごとコピーし、API キーを入力し直してください。貸借取引残高は取り直せません。
