# Chronos Chart

Yahoo! Finance から個別銘柄の株価（始値・高値・安値・終値・出来高）を取得し、
日ごとのテクニカル指標を計算・保存・チャート表示するローカル GUI ツールです。
株価・テクニカル指標に加えて、需給（空売り残高・貸借取引残高）と法定開示（EDINET）を同じチャート上で突き合わせて確認でき、
起動のたびに登録銘柄のデータを自動更新します。

> [Autotechnical](https://github.com/satsuki19980613/Autotechnical) を土台に開発しています。
> 仕様は [docs/SPEC.md](docs/SPEC.md)、進捗は [docs/PLAN.md](docs/PLAN.md) を参照してください。
> 株価・テクニカル指標・需給・法定開示・起動時の自動更新は動作します。**Gemini による AI 分析レポートの生成はまだ実装されていません**（開発中）。

- **GUI**: Python + [pywebview](https://pywebview.flowrl.com/)（画面は HTML / CSS / JavaScript）
- **株価の取得**: [yfinance](https://github.com/ranaroussi/yfinance)
- **需給の取得**: requests + BeautifulSoup（空売り残高・貸借取引残高）
- **法定開示の取得**: EDINET API v2
- **データベース**: SQLite
- **チャート**: [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts)（同梱）
- **API キーの保管**: [keyring](https://github.com/jaraco/keyring)（OS の資格情報ストア）

## 機能

### 登録画面
- 銘柄コード（例: `7203`）・ティッカー（例: `AAPL`）・英語の社名で検索
  - 全角数字でも入力可。4桁の国内コードは東証銘柄（`7203.T`）を先頭に表示
- 検索結果から選択して登録 → **初回は過去1年分の日足を取得**
- 登録済み銘柄の一覧・個別更新・全銘柄更新・削除
  - 更新は最終取得日以降の差分のみ取得（株式分割を検出した場合は全期間を取り直し）
- 空売り残高の一括取得・開示の取得（いずれもジョブとして実行、進捗表示と中断ができます）
  - 空売り残高の一括取得は設定タブで連絡先（`scrape_contact`）を入力するまで実行できません
  - 開示の取得は設定タブで EDINET の API キーを登録するまで実行できません

### ダッシュボード画面
- 最新の株価・前日比
- 主要指標の最新値と判定（強気 / 弱気 / 中立）
- ローソク足チャート
  - メイン: 移動平均・指数平滑移動平均・ボリンジャーバンド・一目均衡表（雲の先行表示あり）・多重移動平均・パラボリック・売買シグナル
  - サブ: 出来高・MACD・RSI・RCI・DMI/ADX・ストキャスティクス・移動平均乖離率・サイコロジカルライン・標準偏差・モメンタム
  - 需給の2ペイン: **空売り残高の合計**（階段線、収集済みの報告義務者の合計を本ツールが算出）／
    **貸借取引残高（日証金）**（融資残高・貸株残高の通常線、欠測日をまたいで結びません）
  - 表示する指標・需給ペインはチップで切り替え（設定は保存されます）。データが無い銘柄はチップを無効化し理由を表示
- 開示イベント
  - チャート上に開示マーカー（大量保有・公開買付などの需給関連は橙、有価証券報告書・半期報告書は水色、その他は灰）
  - 右カラムの「開示イベント」欄に、表示範囲に連動して提出日時・種別・概要・提出事由・提出者名・取下げの有無を一覧表示
  - マーカーをクリックすると該当行が強調され、行をクリックするとチャートがその日付にスクロールします
  - 「開く」で EDINET の書類閲覧ページを OS の既定ブラウザで開きます（本文の取得・保存はしません）
- ダッシュボードから対象銘柄だけの空売り残高・貸借取引残高（日証金）の取得も可能
- 直近のシグナル一覧（ゴールデン/デッドクロス、MACD クロス、RSI 30/70）
- 直近60日の日次データ表

### 出力画面（AI 向けファイル）
- 登録済み銘柄を複数選択し、AI（LLM）に読ませるためのファイルを `output/` に出力
- 形式
  - **テキスト（Markdown）**: 前提条件（データの出典・価格の調整方法・空欄の意味）、指標の定義、銘柄ごとの最新判定（`key`/`status` は英語）、期間内のシグナル、日次データ（CSV ブロック）
  - **CSV**: 全銘柄を 1 つの表に（`symbol` 列で区別）。英語 snake_case で期間入りの列名（`sma_25`, `rsi_14` など）、ISO 日付、古い順、桁区切りなし、UTF-8（BOM なし）
- 期間: 直近20日 / 60日 / 120日 / 全期間
- ファイル名: `technical_<日時>_<銘柄>.md` / `.csv`
- **需給データ（空売り残高・貸借取引残高）は出力に含まれません**（規約により画面表示のみ。§注意事項）

### 設定タブ
- **起動時の自動更新**: オン／オフの切り替え、空売り残高を自動更新に含めるかの切り替え（既定オフ）、
  前回の取得から何分以内はスキップするか
- **EDINET（法定開示）**: API キーの入力・削除・表示、取得手順（サインアップ → CAPTCHA → パスワード → MFA → 連絡先入力の5段階）へのリンク、接続テスト
- **Gemini（AI 分析）**: API キー・モデル名・利用上限（RPM／TPM／RPD）・出力トークン上限・thinking の予算の入力欄
  （**AI 分析そのものは未実装のため、接続テストや実行はまだできません**）
- **空売り残高の取得（karauri.net）**: User-Agent に載せる連絡先、リクエスト間隔（既定10秒・下限5秒）、同一銘柄を再取得しない時間
- 各データソースの出典・規約の要約と、取得したデータを再配布しない旨の表示
- データ保存先がクラウド同期フォルダ（OneDrive 等）の配下にあると推定される場合の警告

### 起動時の自動更新
- アプリを起動するたびに**1回だけ**、登録銘柄のデータを **株価 → 貸借取引残高（日証金） → 開示（EDINET） → 空売り残高（設定でオンの場合のみ）** の順にバックグラウンドで差分更新します
- 画面はブロックされません。ヘッダーに進捗（例:「株価を更新中 3/12」）と中断ボタンが表示されます
- ソースごとに連続2回失敗するとそのソースを打ち切って次に進み、失敗しても起動そのものは妨げません
- **オフにする方法**: 設定タブの「起動時に自動更新する」のチェックを外してください（既定はオン）。
  空売り残高は既定でオフのため、オンにしない限り karauri.net へは自動アクセスしません

### ジョブ（進捗表示と中断）
- 空売り残高の一括取得・開示の取得のように時間がかかる処理は、進捗バーと中断ボタン付きのジョブとして実行します
- 同じ種類のジョブは同時に1つだけ実行できます

## 計算する指標（日ごとに DB と CSV に保存）

| 指標 | 項目 | パラメータ |
| --- | --- | --- |
| 移動平均 | 短期 / 中期 / 長期 | 5 / 25 / 75 |
| ボリンジャーバンド | +2σ / 移動平均 / -2σ | 20日、母標準偏差 |
| MACD | MACD / シグナル | 12, 26 / 9 |
| RSI | 中期 | 14（Wilder） |
| 一目均衡表 | 基準線 / 転換線 / 先行線1 / 先行線2 / 遅行線 | 26 / 9 / (基準+転換)÷2 / 52 / 26日ずらし |
| 指数平滑移動平均 | 短期 / 中期 / 長期 | 5 / 25 / 75 |
| RCI | 短期 / 長期 | 9 / 26 |
| DMI/ADX | +DI / -DI / ADX | 14（Wilder） |
| 多重移動平均（GMMA） | 最短群 / 最長群 | EMA 3,5,8,10,12,15 / EMA 30,35,40,45,50,60 |
| パラボリック | SAR | 加速因子 0.02、上限 0.2 |
| ストキャスティクス | %K / %D | 9 / 3 |
| 移動平均乖離率 | 短期 / 長期 | 25 / 75 |
| サイコロジカルライン | — | 12 |
| 標準偏差 | — | 20 |
| モメンタム | モメンタム / シグナル | 10（当日終値−10日前終値） / 9日単純移動平均 |

パラメータは [app/indicators.py](app/indicators.py) の `PARAMS` でまとめて変更できます。
指標の構成を変えた場合、次回起動時に保存済みの株価から全銘柄の指標と CSV を自動で再計算します。

> 指標の計算には一定期間のデータが必要なため、取得期間の先頭付近は空欄になります
> （例: 移動平均 長期は75日目から、一目の先行線2 は77日目から）。

## セットアップ

Python 3.10 以上が必要です。

```bash
git clone https://github.com/satsuki19980613/Chronos-Chart.git
cd Chronos-Chart
python -m venv .venv
.venv\Scripts\activate        # macOS / Linux は source .venv/bin/activate
pip install -r requirements.txt
```

## 起動

Windows では **`start.bat` をダブルクリック**するだけで起動できます。

- `.venv` フォルダがあればその Python を、なければ PATH 上の Python を使います
- 必要なライブラリが入っていなければ、初回に `requirements.txt` から自動でインストールします
- コンソールを出さずにアプリだけが起動します（エラーは `data/logs/app.log` に記録）
- コマンドプロンプトから `start.bat --debug` で、コンソールと開発者ツール付きで起動します

コマンドから直接起動する場合:

```bash
python main.py
```

開発者ツールを有効にする場合は `python main.py --debug`。

## データの保存先

```
data/
├── chronos.db                  # SQLite（stocks / prices / indicators / settings / fetch_log /
│                                #   short_positions / short_totals / margin_balances /
│                                #   edinet_codes / disclosures / disclosure_links）
├── csv/
│   ├── 7203.T_株価.csv               # 日付・始値・高値・安値・終値・出来高
│   └── 7203.T_テクニカル指標.csv     # 日付・終値・日ごとのテクニカル指標
├── edinet_cache/                # EDINET documents.json の日次キャッシュ（YYYY-MM-DD.json.gz）
│                                #   銘柄で絞り込む前の生データ。銘柄を後から登録したときの再走査に使う
└── logs/app.log
output/                               # 出力タブで作成した AI 向けファイル
```

- `data/csv/` は人が Excel で見るための CSV です（UTF-8 BOM 付き、新しい日付が上、日付は yyyy/mm/dd、
  株価単位の指標は株価と同じ桁・その他は小数2桁）。正となるデータは SQLite 側です。
  - 一目均衡表の遅行線は「25営業日後の終値」をその日の行に置くため、直近25行は空欄になります。
- CSV を Excel で開いたまま更新すると CSV の書き込みだけスキップされ、画面に警告が出ます。
- 保存先は環境変数 `CHRONOS_DATA_DIR`（データ）/ `CHRONOS_OUTPUT_DIR`（出力）で変更できます。
- **`data/` が OneDrive などのクラウド同期フォルダの配下にある場合は要注意です。** SQLite の書き込みと同期ツールが
  競合し、破損や競合コピーの原因になります。設定タブに警告が出た場合は `CHRONOS_DATA_DIR` で同期対象外の場所を
  指定してください。

## API キーの保存先

- EDINET・Gemini の API キーは **OS の資格情報ストア**（`keyring`。Windows では資格情報マネージャー）に保存されます。
  サービス名は `ChronosChart`。**DB・ログ・レポート・エクスポートファイルには一切書き込まれません**。
  画面ではマスク表示（先頭4文字＋`****`）で、「表示」ボタンで一時的に確認できます
- 環境変数 `CHRONOS_EDINET_API_KEY` / `GEMINI_API_KEY` でも指定できます（設定されていればこちらを優先します）
- `keyring` が使えない環境ではキーの保存を拒否し、環境変数での指定を案内します
- **キーが無くても株価・需給（空売り残高・貸借取引残高）の取得は動作します。** 開示（EDINET）の取得と AI 分析だけが
  無効になり、起動時の自動更新では該当ソースを黙ってスキップします

## 別 PC への移行

リポジトリをクローンしただけでは、設定も取得済みデータも引き継がれません
（`data/` は Git 対象外、API キーは PC ごとの資格情報ストアにあります）。

1. **`data/` フォルダをまるごとコピーします。** 設定値（キー以外）・株価・テクニカル指標・需給データ・
   開示キャッシュが引き継がれます
2. 新しい PC で **API キーを入力し直します**（同じキーを使えます。再発行は不要。環境変数での指定でも構いません）

**貸借取引残高（日証金）は取り直せません。** `data/` をコピーしないと、蓄積がその日からやり直しになります。

## 注意事項 / データの出典と規約

- **株価 — Yahoo! Finance（yfinance）**: yfinance は Yahoo! Finance の非公式ライブラリです。Yahoo! の利用規約に
  従い、個人の分析用途でご利用ください。取得データの正確性・継続的な提供は保証されません。
  株価は分割調整済み・配当未調整の値です。
- **空売り残高 — karauri.net（元データは JPX）**: チャートに出る合計値は
  **本ツールが算出した値**であり、サイトの公表値そのものではありません。**0 は「空売りが無い」ではなく
  「発行済株式総数の0.5%以上を報告している機関がいない」**ことを意味します（0.5%未満のポジションはそもそも
  公表されません）。銘柄別ページには直近100件までしか載らないため、収集を始めた直後の期間は合計が過小になる
  ことがあります。**設定タブで連絡先（User-Agent に載せる `scrape_contact`）を入力しない限り、本ツールは
  karauri.net へのアクセスを一切行いません。** アクセスは1件ずつ間隔（既定10秒）を空けて直列に行い、
  403 / 429 を受けた時点でその回の取得を中止します。
- **貸借取引残高 — 日本証券金融**: 日証金の規約により、**私的利用の範囲を超える利用・第三者への提供は
  禁止**されています。対象は**貸借銘柄のみ**です。配布ファイルは上場市場ごとに行が分かれており、本ツールは東証の行だけを
  採用するため、名証・福証・札証のみに上場する銘柄は対象外になります。
  過去分のファイルは提供されていないため、**本ツールで取得を始めた日以降のデータしかありません**。
  **一度取得できなかった日を後から取り直すことはできません。**
- **法定開示 — EDINET（金融庁）**: コンテンツは「公共データ利用規約（第1.0版・PDL1.0）」に準拠した条件で
  利用できます。利用にあたっては**出典の記載**（例:「出典：EDINET閲覧（提出）サイト」）に加え、
  **本ツールが加工して表示している旨**の記載が必要です（画面のイベント欄にはこの2点を表示しています）。
  書類一覧は **EDINET API v2 からのみ**取得し、サイトのスクレイピングは行いません。書類閲覧ページは
  OS の既定ブラウザで開くだけで、本文の機械的な取得・保存はしません。
  **決算短信・業績予想の修正（TDnet の管轄）は対象外です。決算発表日はチャートに表示されません。**
  EDINET にあるのは有価証券報告書・半期報告書などの法定開示であり、決算発表とは提出のタイミングが異なります。

  出力（AI 向けファイル）・AI への送信・レポートには一切含めません。
- 一目均衡表の将来の雲の日付は土日のみを除いた営業日で近似しています（祝日は考慮しません）。
