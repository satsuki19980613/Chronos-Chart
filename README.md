# Chronos Chart

Yahoo! Finance から個別銘柄の株価（始値・高値・安値・終値・出来高）を取得し、
日ごとのテクニカル指標を計算・保存・チャート表示するローカル GUI ツールです。
株価・テクニカル指標に加えて、需給（空売り残高・貸借取引残高）と法定開示（EDINET）を同じチャート上で突き合わせて確認でき、
有価証券報告書・半期報告書から**財務数値**を取り込んで指標に落とし、Gemini による AI 分析レポートまで作れます。
起動のたびに登録銘柄のデータを自動更新します。

> [Autotechnical](https://github.com/satsuki19980613/Autotechnical) を土台に開発しています。
> 仕様は [docs/SPEC.md](docs/SPEC.md)、進捗は [docs/PLAN.md](docs/PLAN.md) を参照してください。
> 株価・テクニカル指標・需給・法定開示・**財務数値**・起動時の自動更新・**Gemini による AI 分析レポート**まで動作します。
> **はじめて使う場合は[セットアップ](#セットアップ)を上から順に読んでください。**

- **GUI**: Python + [pywebview](https://pywebview.flowrl.com/)（画面は HTML / CSS / JavaScript）
- **株価の取得**: [yfinance](https://github.com/ranaroussi/yfinance)
- **需給の取得**: requests + BeautifulSoup（空売り残高・貸借取引残高）
- **法定開示の取得**: EDINET API v2
- **データベース**: SQLite
- **チャート**: [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts)（同梱）
- **API キーの保管**: [keyring](https://github.com/jaraco/keyring)（OS の資格情報ストア）

## 機能

### 登録画面
- 銘柄コード（例: `7203`）・ティッカー（例: `AAPL`）・英語の社名で検索
  - 全角数字でも入力可。4桁の国内コードは東証銘柄（`7203.T`）を先頭に表示
- 検索結果から選択して登録 → **初回は過去1年分の日足を取得**
- 登録済み銘柄の一覧・個別更新・全銘柄更新・削除
  - 更新は最終取得日以降の差分のみ取得（株式分割を検出した場合は全期間を取り直し）
- 空売り残高の一括取得・開示の取得・**財務数値の取得**（いずれもジョブとして実行、進捗表示と中断ができます）
  - 空売り残高の一括取得は設定タブで連絡先（`scrape_contact`）を入力するまで実行できません
  - 開示の取得と財務数値の取得は設定タブで EDINET の API キーを登録するまで実行できません
  - **財務数値の取得は開示の取得より後に実行してください。** 取得対象（有価証券報告書・半期報告書）は
    開示の一覧から選ぶため、開示が入っていないと対象0件になります
  - 財務数値は**起動時の自動更新に含まれません**（年2回しか増えないため。開示の取得後に案内が出ます）

### ダッシュボード画面
- 最新の株価・前日比
- 主要指標の最新値と判定（強気 / 弱気 / 中立）
- ローソク足チャート
  - メイン: 移動平均・指数平滑移動平均・ボリンジャーバンド・一目均衡表（雲の先行表示あり）・多重移動平均・パラボリック・売買シグナル
  - サブ: 出来高・MACD・RSI・RCI・DMI/ADX・ストキャスティクス・移動平均乖離率・サイコロジカルライン・標準偏差・モメンタム
  - 需給の2ペイン: **空売り残高の合計**（階段線、収集済みの報告義務者の合計を本ツールが算出）／
    **貸借取引残高（日証金）**（融資残高・貸株残高の通常線、欠測日をまたいで結びません）
  - 表示する指標・需給ペインはチップで切り替え（設定は保存されます）。データが無い銘柄はチップを無効化し理由を表示
- 開示イベント
  - チャート上に開示マーカー（大量保有・公開買付などの需給関連は橙、有価証券報告書・半期報告書は水色、その他は灰）
  - 右カラムの「開示イベント」欄に、表示範囲に連動して提出日時・種別・概要・提出事由・提出者名・取下げの有無を一覧表示
  - マーカーをクリックすると該当行が強調され、行をクリックするとチャートがその日付にスクロールします
  - 「開く」で EDINET の書類閲覧ページを OS の既定ブラウザで開きます（本文の取得・保存はしません）
- ダッシュボードから対象銘柄だけの空売り残高・貸借取引残高（日証金）の取得も可能
- 直近のシグナル一覧（ゴールデン/デッドクロス、MACD クロス、RSI 30/70）
- 直近60日の日次データ表

### 出力画面（AI 向けファイル）
- 登録済み銘柄を複数選択し、AI（LLM）に読ませるためのファイルを `output/` に出力
- 形式
  - **テキスト（Markdown）**: 前提条件（データの出典・価格の調整方法・空欄の意味）、指標の定義、銘柄ごとの最新判定（`key`/`status` は英語）、期間内のシグナル、日次データ（CSV ブロック）
  - **CSV**: 全銘柄を 1 つの表に（`symbol` 列で区別）。英語 snake_case で期間入りの列名（`sma_25`, `rsi_14` など）、ISO 日付、古い順、桁区切りなし、UTF-8（BOM なし）
- 期間: 直近20日 / 60日 / 120日 / 全期間
- ファイル名: `technical_<日時>_<銘柄>.md` / `.csv`
- **需給データ（空売り残高・貸借取引残高）は出力に含まれません**（規約により画面表示のみ。§注意事項）

### レポート画面（AI 分析レポート）
- 銘柄と期間（直近20日 / 60日 / 120日）を選び、**手動で実行**します（自動実行・定期実行はしません）
- 実行前に確認ダイアログで、使用モデル・**入力トークンの見積り**（`count_tokens` の実測）・本日の残量（RPD／TPM）・
  送信されるデータの種別を表示します
- **送信するのは銘柄情報・株価・テクニカル指標・財務指標・EDINET の開示一覧（本文は含まない）だけです。**
  需給データ（空売り残高・貸借取引残高）は送信しません（[注意事項](#注意事項)）
- **生の財務諸表は送りません。** アプリ側で成長率・CAGR・営業CFマージン・フリーキャッシュフロー・
  アクルーアル・トレンド（改善/横ばい/悪化）まで計算し、**1指標1行**にまとめて渡します
  （LLM は表の数値どうしの計算が苦手なため、計算をアプリに寄せています）
- **テクニカルは圧縮して渡します。** 直近20日は日々の値、それ以前は期間の四本値・出来高・
  シグナルの発生日・指標ごとの方向の要約に置き換えます。
  実測（9984.T）で 120日分が約53,000トークン → **16,305トークン**に下がり、財務を足しても総量は減っています
- レポートには**財務ハイライト**（KPI カードと図）・**財務指標の表**・中間期（半期報告書）の表が出ます
- **AI が根拠に書いた数値が、渡したデータの中に実在するかを機械的に照合**し、結果をレポートに載せます
  （数字が在るかを見るだけで、使い方の正しさまでは判定しません）
- Gemini には JSON だけを返させ（HTML は書かせない）、レポートの HTML はアプリ側が組み立てて
  `data/reports/report_<銘柄>_<日時>.html` に保存します。一覧から「開く」で既定のブラウザで開けます
- レポートには免責（投資助言ではない・AI の出力を検証していない・データの出典・**決算短信や業績修正は対象外**）を必ず載せます
- 使用量は太平洋時間の日付ごとに数えます（無料枠のリセットが太平洋時間の0時＝日本時間の当日16時または17時のため）。
  日次上限の 429 を受けた場合はその日そのモデルへの送信を打ち切り、設定タブから手動で解除できます

### 設定タブ
- **起動時の自動更新**: オン／オフの切り替え、空売り残高を自動更新に含めるかの切り替え（既定オフ）、
  前回の取得から何分以内はスキップするか
- **EDINET（法定開示）**: API キーの入力・削除・表示、取得手順（サインアップ → CAPTCHA → パスワード → MFA → 連絡先入力の5段階）へのリンク、接続テスト
- **Gemini（AI 分析）**: API キー・モデル名・利用上限（RPM／TPM／RPD）・出力トークン上限・thinking の予算の入力欄、
  接続テスト、打ち切りフラグの手動解除。**RPM・TPM・RPD のいずれかが 0 の間は AI 機能が無効**です
  （無料枠の数値は公式ドキュメントに表が無いため、[AI Studio のレート制限ページ](https://aistudio.google.com/rate-limit)で自分の値を確認して入力してください）
- **空売り残高の取得（karauri.net）**: User-Agent に載せる連絡先、リクエスト間隔（既定10秒・下限5秒）、同一銘柄を再取得しない時間
- 各データソースの出典・規約の要約と、取得したデータを再配布しない旨の表示
- データ保存先がクラウド同期フォルダ（OneDrive 等）の配下にあると推定される場合の警告

### 起動時の自動更新
- アプリを起動するたびに**1回だけ**、登録銘柄のデータを **株価 → 貸借取引残高（日証金） → 開示（EDINET） → 空売り残高（設定でオンの場合のみ）** の順にバックグラウンドで差分更新します
- 画面はブロックされません。ヘッダーに進捗（例:「株価を更新中 3/12」）と中断ボタンが表示されます
- ソースごとに連続2回失敗するとそのソースを打ち切って次に進み、失敗しても起動そのものは妨げません
- **オフにする方法**: 設定タブの「起動時に自動更新する」のチェックを外してください（既定はオン）。
  空売り残高は既定でオフのため、オンにしない限り karauri.net へは自動アクセスしません

### ジョブ（進捗表示と中断）
- 空売り残高の一括取得・開示の取得のように時間がかかる処理は、進捗バーと中断ボタン付きのジョブとして実行します
- 同じ種類のジョブは同時に1つだけ実行できます

## 計算する指標（日ごとに DB と CSV に保存）

| 指標 | 項目 | パラメータ |
| --- | --- | --- |
| 移動平均 | 短期 / 中期 / 長期 | 5 / 25 / 75 |
| ボリンジャーバンド | +2σ / 移動平均 / -2σ | 20日、母標準偏差 |
| MACD | MACD / シグナル | 12, 26 / 9 |
| RSI | 中期 | 14（Wilder） |
| 一目均衡表 | 基準線 / 転換線 / 先行線1 / 先行線2 / 遅行線 | 26 / 9 / (基準+転換)÷2 / 52 / 26日ずらし |
| 指数平滑移動平均 | 短期 / 中期 / 長期 | 5 / 25 / 75 |
| RCI | 短期 / 長期 | 9 / 26 |
| DMI/ADX | +DI / -DI / ADX | 14（Wilder） |
| 多重移動平均（GMMA） | 最短群 / 最長群 | EMA 3,5,8,10,12,15 / EMA 30,35,40,45,50,60 |
| パラボリック | SAR | 加速因子 0.02、上限 0.2 |
| ストキャスティクス | %K / %D | 9 / 3 |
| 移動平均乖離率 | 短期 / 長期 | 25 / 75 |
| サイコロジカルライン | — | 12 |
| 標準偏差 | — | 20 |
| モメンタム | モメンタム / シグナル | 10（当日終値−10日前終値） / 9日単純移動平均 |

パラメータは [app/indicators.py](app/indicators.py) の `PARAMS` でまとめて変更できます。
指標の構成を変えた場合、次回起動時に保存済みの株価から全銘柄の指標と CSV を自動で再計算します。

> 指標の計算には一定期間のデータが必要なため、取得期間の先頭付近は空欄になります
> （例: 移動平均 長期は75日目から、一目の先行線2 は77日目から）。

## セットアップ

ここだけ読めば最初から最後まで通せるように書いてあります。**上から順にやってください。**

| 何をするか | 必須か | かかる時間 |
|---|---|---|
| 1. Python と本体の用意 | 必須 | 5分 |
| 2. 初回起動 | 必須 | 1分 |
| 3. EDINET の API キー | **開示と財務数値を使うなら必須** | 15分（MFA があるため） |
| 4. Gemini の API キーと上限 | **AI 分析を使うなら必須** | 10分 |
| 5. karauri.net 用の連絡先 | 空売り残高を使うなら必須 | 1分 |
| 6. 最初のデータ取り込み | 必須 | 銘柄数による |

API キーが無くても**株価とテクニカル指標は動きます**。開示・財務数値・AI 分析だけが無効になります。

---

### 1. Python と本体の用意

**Python 3.10 以上**が必要です。`python --version` で確認してください。
入っていなければ [python.org](https://www.python.org/downloads/) から入れます。
**インストーラの「Add python.exe to PATH」に必ずチェックを入れてください。**

```bash
git clone https://github.com/satsuki19980613/Chronos-Chart.git
cd Chronos-Chart
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux では `.venv\Scripts\activate` の代わりに `source .venv/bin/activate` です。

> `.venv` を作っておくと、`start.bat` がそちらの Python を優先して使います。
> 作らずに `start.bat` をダブルクリックしても、足りないライブラリは初回に自動で入ります。

### 2. 初回起動

Windows なら **`start.bat` をダブルクリック**します。コンソールは出ず、アプリのウィンドウだけが開きます。

- うまく起動しないときは、コマンドプロンプトから `start.bat --debug` で実行してください。
  コンソールと開発者ツールが付き、エラーが読めます
- エラーは `data/logs/app.log` にも残ります

この時点で **登録タブから銘柄を検索・登録して、株価とチャートは使えます。**

### 3. EDINET の API キーを取る（開示・財務数値に必要）

金融庁の EDINET API v2 のキーです。**無料ですが、手続きが5段階あって15分ほどかかります。**

1. [EDINET API の登録ページ](https://api.edinet-fsa.go.jp/api/auth/index.aspx?mode=1)を開く
2. メールアドレスを入れてサインアップ
3. CAPTCHA（画像認証）を通す
4. パスワードを設定する
5. **MFA（多要素認証）**: 電話番号を登録し、SMS か音声通話で届くコードを入れる
6. 連絡先情報を入力すると、**サブスクリプションキー**が表示されます

取れたら、アプリの **設定タブ → EDINET** にキーを貼り付けて保存し、**「接続テスト」**を押してください。
成功すれば準備完了です。

> - キーは **OS の資格情報マネージャー**に入ります。DB にもログにもレポートにも書き込まれません
> - **2年間まったく使わないとキーは自動削除されます**
> - 環境変数 `CHRONOS_EDINET_API_KEY` でも指定できます（設定してあればそちらが優先）

### 4. Gemini の API キーと上限を設定する（AI 分析に必要）

#### 4-1. キーを取る

[Google AI Studio](https://aistudio.google.com/apikey) で API キーを作成します。Google アカウントがあれば数分です。

#### 4-2. 設定タブに入れる

**設定タブ → Gemini** に、次の**5つすべて**を入れます。

| 欄 | 何を入れるか |
|---|---|
| API キー | 4-1 で作ったキー |
| モデル名 | 例: `gemini-2.5-flash`（動作確認済み） |
| RPM（1分あたりリクエスト） | 自分のアカウントの値 |
| TPM（1分あたりトークン） | 同上 |
| RPD（1日あたりリクエスト） | 同上 |

**RPM・TPM・RPD のどれかが 0 のあいだは AI 機能が有効になりません。**

**自分の値は [AI Studio のレート制限ページ](https://aistudio.google.com/rate-limit) で確認してください。**
無料枠の数値は公式ドキュメントに表として載っていないため、アプリ側では自動取得せず手入力にしています。

> **この上限は API キー単位ではなく Google Cloud のプロジェクト単位です。**
> 同じプロジェクトを他のツールでも使っていると、本ツールの残量表示より実際の残りは少なくなります。

入れ終わったら **「接続テスト」**を押します（最小のプロンプトを1回だけ送ります）。

> RPD の欄は、**このアプリが1日に送る回数の上限としても働きます。**
> 使いすぎが心配なら、アカウントの実際の上限より小さい数字（例: `10`）を入れておけば、
> アプリ側がそこで止めます。詳しくは[Gemini API の料金と使用量の上限](#gemini-api-の料金と使用量の上限)を参照してください。

### 5. karauri.net 用の連絡先を入れる（空売り残高を使う場合）

**設定タブ → 空売り残高の取得** の「連絡先」に、**メールアドレスかリポジトリ URL**を入れます。

**この文字列は karauri.net へのリクエストごとに User-Agent として送信されます。**
相手サイトに迷惑をかけたときに連絡が取れるようにするためのもので、**空欄のあいだは一括取得を実行できません。**

リクエスト間隔は既定10秒（下限5秒）です。**短くしないでください。**

### 6. 最初のデータを取り込む

**この順番でやってください。** 開示を取り込んでいないと、財務数値の取得が対象書類を見つけられません。

1. **銘柄を登録する** — 登録タブで検索して登録します（初回は過去1年分の日足を取得）
2. **「開示を取得」** — EDINET の書類一覧を日付ごとに取ります。
   登録直後にも取得を提案するダイアログが出ます。初回は1年分で数分かかります
3. **「財務数値を取得」** — 有価証券報告書・半期報告書から売上・利益・キャッシュフロー・ROE などを取り込みます。
   1銘柄あたり年2件ほどなのですぐ終わります
4. **レポートタブから「分析を実行」** — 銘柄と期間を選び、確認ダイアログの内容を見てから実行します

> **財務数値の取得は起動時の自動更新に含まれません。** 年2回しか増えないので、
> 新しい有価証券報告書が出たときに手動で押してください（開示を取得したあとに案内が出ます）。

### セットアップが終わったかの確認

- 登録タブに銘柄が並び、ダッシュボードにローソク足が出る → **株価 OK**
- 設定タブの EDINET 接続テストが成功する → **開示 OK**
- ダッシュボードのチャートに開示マーカー（色付きの印）が出る → **開示の突合 OK**
- 設定タブの Gemini 接続テストが成功し、レポートタブの「分析を実行」が押せる → **AI 分析 OK**
- レポートに「財務ハイライト」の数字が出る（「財務数値は未取得」ではない） → **財務数値 OK**

### つまずきやすいところ

| 症状 | 原因と対処 |
|---|---|
| `start.bat` をダブルクリックしても何も起きない | `start.bat --debug` をコマンドプロンプトから実行してエラーを読む。`data/logs/app.log` も見る |
| 「開示を取得」が押せない | EDINET の API キーが未設定。設定タブで登録する |
| 「財務数値を取得」を押しても対象0件 | 先に「開示を取得」を実行する。取得対象は開示一覧にある有報・半期報から選ばれる |
| 「分析を実行」が押せない | Gemini のモデル名・RPM・TPM・RPD のどれかが未入力（0）。5つすべて埋める |
| 「空売り残高を一括取得」が押せない | 設定タブの連絡先が空欄 |
| 設定タブにクラウド同期の警告が出る | `data/` が OneDrive 配下にある。環境変数 `CHRONOS_DATA_DIR` で同期対象外の場所を指定する（下記） |
| レポートに「財務数値は未取得」と出る | その銘柄の財務数値をまだ取り込んでいない。手順6の3を実行する |

## Gemini API の料金と使用量の上限

AI 分析は Google の Gemini API を使います。**無料枠の範囲でも動きます**が、
使いすぎが心配な場合の選択肢を整理しておきます（2026年9月時点の公式ドキュメントに基づく。**変更され得ます**）。

### 前払い（プリペイド）はある

Gemini API には **Prepay（前払い）プラン**があります。先に残高を買っておき、
**残高がゼロになった時点で、その請求先アカウントに紐づく全プロジェクトの API キーが一斉に止まります。**
使いすぎを構造的に防ぎたい場合はこれがいちばん確実です。

- 最低 **$5** から、残高の上限は **$5,000**
- **購入から1年で失効**し、**返金されません**
- 残高が少なくなったら自動でチャージする設定もできます

### 月ごとの上限はある。日ごとの上限は無い

課金アカウントには**ティアごとの月間の上限**があり、超えるとその請求サイクルのあいだ API が止まります
（Tier 1 で $250、Tier 2 で $2,000、Tier 3 は $20,000 以上）。
**AI Studio からプロジェクト単位で自分の月間上限を設定することもできます**（実験的機能）。

**一方、「1日いくらまで」という日単位の支出上限は用意されていません。**
また、レート制限（RPM / TPM / RPD）はティアによって自動で決まるもので、**利用者が任意に下げる設定項目もありません。**

### このアプリ側で1日の回数を絞る

そのため、**日ごとの歯止めはこのアプリが持っています。**
設定タブの **RPD**（1日あたりリクエスト上限）は、本アプリが自前で数えて止めるためのものです。

- アカウントの実際の上限より**小さい数字を入れておけば、そこでアプリが止まります**（例: `10`）
- 数えているのは**太平洋時間の日付**です（無料枠のリセットが太平洋時間の0時＝日本時間の当日16時または17時のため）
- 分析は**手動実行のみ**で、自動実行・定期実行は一切しません
- 実行前の確認ダイアログに、**入力トークンの見積り**と**本日の残量**が出ます

> ただしこれは**アプリ側の自己申告のカウンタ**です。同じプロジェクトを他のツールでも使っている場合、
> 実際の残量はこの表示より少なくなります。**課金そのものを止めたいなら Prepay を使ってください。**

出典: [Billing | Gemini API](https://ai.google.dev/gemini-api/docs/billing) ／ [Rate limits | Gemini API](https://ai.google.dev/gemini-api/docs/rate-limits)

## 起動

Windows では **`start.bat` をダブルクリック**するだけで起動できます。

- `.venv` フォルダがあればその Python を、なければ PATH 上の Python を使います
- 必要なライブラリが入っていなければ、初回に `requirements.txt` から自動でインストールします
- コンソールを出さずにアプリだけが起動します（エラーは `data/logs/app.log` に記録）
- コマンドプロンプトから `start.bat --debug` で、コンソールと開発者ツール付きで起動します

コマンドから直接起動する場合:

```bash
python main.py
```

開発者ツールを有効にする場合は `python main.py --debug`。

## データの保存先

```
data/
├── chronos.db                  # SQLite（stocks / prices / indicators / settings / fetch_log /
│                                #   short_positions / short_totals / margin_balances /
│                                #   edinet_codes / disclosures / disclosure_links /
│                                #   financials / financial_docs / ai_usage / ai_reports）
├── csv/
│   ├── 7203.T_株価.csv               # 日付・始値・高値・安値・終値・出来高
│   └── 7203.T_テクニカル指標.csv     # 日付・終値・日ごとのテクニカル指標
├── edinet_cache/                # EDINET documents.json の日次キャッシュ（YYYY-MM-DD.json.gz）
│                                #   銘柄で絞り込む前の生データ。銘柄を後から登録したときの再走査に使う
├── reports/                     # AI 分析レポート（report_<銘柄>_<日時>.html。単一 HTML）
└── logs/app.log                 # AI の応答がスキーマに合わなかったときの生ログもここに残る
output/                               # 出力タブで作成した AI 向けファイル
```

- `data/csv/` は人が Excel で見るための CSV です（UTF-8 BOM 付き、新しい日付が上、日付は yyyy/mm/dd、
  株価単位の指標は株価と同じ桁・その他は小数2桁）。正となるデータは SQLite 側です。
  - 一目均衡表の遅行線は「25営業日後の終値」をその日の行に置くため、直近25行は空欄になります。
- CSV を Excel で開いたまま更新すると CSV の書き込みだけスキップされ、画面に警告が出ます。
- 保存先は環境変数 `CHRONOS_DATA_DIR`（データ）/ `CHRONOS_OUTPUT_DIR`（出力）で変更できます。
- **`data/` が OneDrive などのクラウド同期フォルダの配下にある場合は要注意です。** SQLite の書き込みと同期ツールが
  競合し、破損や競合コピーの原因になります。設定タブに警告が出た場合は `CHRONOS_DATA_DIR` で同期対象外の場所を
  指定してください。

## API キーの保存先

- EDINET・Gemini の API キーは **OS の資格情報ストア**（`keyring`。Windows では資格情報マネージャー）に保存されます。
  サービス名は `ChronosChart`。**DB・ログ・レポート・エクスポートファイルには一切書き込まれません**。
  画面ではマスク表示（先頭4文字＋`****`）で、「表示」ボタンで一時的に確認できます
- 環境変数 `CHRONOS_EDINET_API_KEY` / `GEMINI_API_KEY` でも指定できます（設定されていればこちらを優先します）
- `keyring` が使えない環境ではキーの保存を拒否し、環境変数での指定を案内します
- **キーが無くても株価・需給（空売り残高・貸借取引残高）の取得は動作します。** 開示（EDINET）の取得と AI 分析だけが
  無効になり、起動時の自動更新では該当ソースを黙ってスキップします

## 別 PC への移行

リポジトリをクローンしただけでは、設定も取得済みデータも引き継がれません
（`data/` は Git 対象外、API キーは PC ごとの資格情報ストアにあります）。

1. **`data/` フォルダをまるごとコピーします。** 設定値（キー以外）・株価・テクニカル指標・需給データ・
   開示キャッシュが引き継がれます
2. 新しい PC で **API キーを入力し直します**（同じキーを使えます。再発行は不要。環境変数での指定でも構いません）

**貸借取引残高（日証金）は取り直せません。** `data/` をコピーしないと、蓄積がその日からやり直しになります。

## 注意事項 / データの出典と規約

- **株価 — Yahoo! Finance（yfinance）**: yfinance は Yahoo! Finance の非公式ライブラリです。Yahoo! の利用規約に
  従い、個人の分析用途でご利用ください。取得データの正確性・継続的な提供は保証されません。
  株価は分割調整済み・配当未調整の値です。
- **空売り残高 — karauri.net（元データは JPX）**: チャートに出る合計値は
  **本ツールが算出した値**であり、サイトの公表値そのものではありません。**0 は「空売りが無い」ではなく
  「発行済株式総数の0.5%以上を報告している機関がいない」**ことを意味します（0.5%未満のポジションはそもそも
  公表されません）。銘柄別ページには直近100件までしか載らないため、収集を始めた直後の期間は合計が過小になる
  ことがあります。**設定タブで連絡先（User-Agent に載せる `scrape_contact`）を入力しない限り、本ツールは
  karauri.net へのアクセスを一切行いません。** アクセスは1件ずつ間隔（既定10秒）を空けて直列に行い、
  403 / 429 を受けた時点でその回の取得を中止します。
- **貸借取引残高 — 日本証券金融**: 日証金の規約により、**私的利用の範囲を超える利用・第三者への提供は
  禁止**されています。対象は**貸借銘柄のみ**です。配布ファイルは上場市場ごとに行が分かれており、本ツールは東証の行だけを
  採用するため、名証・福証・札証のみに上場する銘柄は対象外になります。
  過去分のファイルは提供されていないため、**本ツールで取得を始めた日以降のデータしかありません**。
  **一度取得できなかった日を後から取り直すことはできません。**
- **法定開示 — EDINET（金融庁）**: コンテンツは「公共データ利用規約（第1.0版・PDL1.0）」に準拠した条件で
  利用できます。利用にあたっては**出典の記載**（例:「出典：EDINET閲覧（提出）サイト」）に加え、
  **本ツールが加工して表示している旨**の記載が必要です（画面のイベント欄にはこの2点を表示しています）。
  書類一覧は **EDINET API v2 からのみ**取得し、サイトのスクレイピングは行いません。書類閲覧ページは
  OS の既定ブラウザで開くだけで、本文の機械的な取得・保存はしません。
  **決算短信・業績予想の修正（TDnet の管轄）は対象外です。決算発表日はチャートに表示されません。**
  EDINET にあるのは有価証券報告書・半期報告書などの法定開示であり、決算発表とは提出のタイミングが異なります。
- **取得したデータは再配布・公開しないでください。** 空売り残高・貸借取引残高は画面表示のみに使い、
  出力（AI 向けファイル）・AI への送信・レポートには一切含めません。
- 一目均衡表の将来の雲の日付は土日のみを除いた営業日で近似しています（祝日は考慮しません）。
- 本ツールの判定・シグナル・需給データの表示は機械的な計算結果であり、投資助言ではありません。
