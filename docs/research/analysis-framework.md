## 1. セルサイド／バイサイドのアナリストレポートの標準的な構成

### 1-1. 日本国内の自主規制上の要件（日本証券業協会・日本証券アナリスト協会）

- 日本証券業協会「アナリスト・レポートの取扱い等に関する規則」は、レーティングまたは目標株価を記載する場合、
  **レーティングの定義並びに目標株価についての根拠及び達成の予想期間を明確に表示すること**を求めている。
  出典: [アナリスト・レポートの取扱い等に関する規則](https://www.jsda.or.jp/about/kisoku/1502_analystreport_kiosku.pdf)、
  [同・考え方](https://www.jsda.or.jp/shijyo/seido/jishukisei/web-handbook/103_koukoku/1502_analystreport_kangaekata.pdf)
- 同規則は、個別企業の**株価・業績・増減資・配当等の予測**や新技術・新製品・資源開発等の予測を行う場合、
  「自己の判断・評価等が入るときは根拠の表示が必要」と定める。さらに「投資者の投資判断を誤らせるおそれのある表示」
  を禁じている。出典: 同上、[日本証券業協会「アナリスト・レポート」解説](https://www.jsda.or.jp/shijyo/seido/jishukisei/words/0004.html)
- 日本証券アナリスト協会「アナリスト・レポート作成の際の留意事項」（2003年）も存在するが、本調査ではPDFの構造上
  本文を正確に抽出できなかったため、内容の要約は上記日証協規則の範囲にとどめる。
  出典: [日本証券アナリスト協会規律委員会 資料（PDF、未展開）](https://www.saa.or.jp/ethics/pdf/kiritsuanalystreport.pdf)

**→ 実務上の含意**: 「評価（強気・弱気・中立）」だけを出すのではなく、**根拠・前提・達成期間（時間軸）を必ず併記する**
ことが日本の自主規制上も標準的な型である。現行スキーマの `verdict` は根拠なしに単独では出せない設計にすべき。

### 1-2. 欧米（CFA協会基準・投資銀行実務）の標準構成

複数の実務解説（CFA Institute準拠を謳う教材、Corporate Finance Institute、Wall Street Prep 等）に共通する構成は以下の順序:

1. **エグゼクティブサマリー**（投資判断・目標株価・要点）
2. **投資テーゼ（Investment Thesis）**: なぜアウト／アンダーパフォームすると考えるか、カタリスト（きっかけとなる材料）は何か
3. **企業概要（ビジネスモデル）**
4. **業界・競争環境分析**
5. **財務分析**（実績のトレンド、比率分析）
6. **バリュエーション**（DCF・類似企業比較など複数モデル）
7. **目標株価**（通常12カ月の目標）とその前提
8. **リスク要因**
9. （ESG・開示・利益相反の開示）

出典: [CFA Level I – Elements of a Company Research Report (AnalystPrep)](https://analystprep.com/cfa-level-1-exam/equity/elements-of-company-research-report/)、
[Wall Street Prep – Equity Research Report Format](https://www.wallstreetprep.com/knowledge/sample-equity-research-report/)、
[Corporate Finance Institute – Equity Research Report](https://corporatefinanceinstitute.com/resources/valuation/equity-research-report/)

**重要な指摘（複数の実務解説が一致）**:
- 「投資テーゼが先、バリュエーションは投資テーゼを検証する道具」であり、**目標株価は最初に決めるのではなく、
  バリュエーションから逆算する（結論ありきにしない）**という順序が強調されている。
- リスク要因の節は「投資テーゼが崩れる可能性のある事象」を列挙する場所と位置づけられ、
  「業績要因・財務要因・規制／法的要因」に大別されるとされる（分類の粒度はレポートごとに異なる）。
  出典: [AnalystPrep – Elements of a Company Research Report](https://analystprep.com/cfa-level-1-exam/equity/elements-of-company-research-report/)

**→ 実務上の含意**: 現行スキーマは `technical`（根拠→評価）/`disclosure`（根拠→評価）が並列だが、
標準的な型では **「投資テーゼ」という上位概念が先にあり、テクニカル・ファンダメンタル・開示はそれを支える／
反証する材料として位置づけられる**。並列列挙ではなく、統合された物語（なぜ・何が変われば崩れるか）を
明示的に書かせるフィールドがあるとよい。

## 2. ファンダメンタルズとテクニカルの併用の実務的な枠組み

- 通説として「**ファンダメンタルズ分析で銘柄を選び、テクニカル分析で売買タイミングを計る**」という
  役割分担が広く紹介されている（証券会社の投資教育コンテンツに共通）。
  出典: [マネックス証券「テクニカル分析とは」](https://info.monex.co.jp/technical-analysis/column/001.html)、
  [SBIネオトレード証券「ファンダメンタルズ分析」](https://www.sbineotrade.jp/stock/beginner/fundamental-analysis.html)、
  [ティッカートーク](https://tickertalk.co.jp/knowledge/2005/)
- この役割分担では、**両者は「矛盾する」ものというより「時間軸が違う」ものとして扱われる**のが通説の骨子:
  ファンダメンタルズは本質的価値＝中長期の妥当性、テクニカルは需給・心理＝短期のタイミング。
  したがって「ファンダは強気だがテクニカルは弱い」という状況は、**矛盾ではなく「良い銘柄だが今はタイミングが
  悪い（またはその逆）」という時間軸のズレとして解釈するのが実務的な扱い方**とされる。
  出典: 同上（複数証券会社の投資教育コンテンツで共通の説明）
- 併用にあたっての注意点として、「分析を複雑化しすぎるとエントリーポイントが極端に少なくなる」という
  弊害も指摘されている。
  出典: [am-expo「テクニカル分析とファンダメンタルズ分析どっちを使うべきか」](https://www.am-expo.jp/hub/ja-jp/blog/article_57.html)

**→ 実務上の含意**: `technical` と `disclosure/fundamental` を単純併記するのではなく、
**「両者が一致しているか、時間軸のズレとして説明できるか」を明示させるフィールド**（例:
`consistency`: テクニカルとファンダの評価が一致／不一致で、不一致なら時間軸のズレとして言語化）
を追加する価値がある。

## 3. イベントドリブン分析（開示・コーポレートアクションの一般的解釈）

以下はいずれも「一般にこう解釈される」という通説の整理であり、個別銘柄への当てはめや売買推奨ではない。

### 3-1. 大量保有報告書（5%ルール）
- 5%以上の株式保有者に開示義務を課す制度。市場の公正性・透明性確保が目的。
  出典: [松井証券 FAQ](https://support.matsui.co.jp/faq/show/1944)、[岡三オンライン](https://www.okasan-online.co.jp/jp/dealings/5per_rule.html)
- 通説: **M&A・第三者割当など「事実として先に株価に織り込まれる」性質の取得では、報告書自体の株価インパクトは
  限定的**とされる一方、**アクティビストによる段階的な買い集めでは、報告書の提出自体が新たな情報として
  株価に影響を与えることがある**とされる。
  出典: [野村総合研究所「大量保有報告制度と株主アクティビズム」](https://www.nri.com/jp/media/column/osaki/20230509.html)

### 3-2. 公開買付（TOB）
- TOBは対象企業株価に**プレミアムが上乗せされる**典型的イベントとされる。
- 通説上のリスク: **TOBが不成立に終わった場合、プレミアムが剥落し、発表前水準かそれ以下まで下落しうる**。
- 学術研究では、イベント日前後の累積超過リターンを検証する「イベントスタディ」の枠組みが用いられる。
  出典: [国立国会図書館デジタルコレクション「株式公開買い付け(TOB)に対する市場の反応」](https://dl.ndl.go.jp/view/prepareDownload?itemId=info:ndljp/pid/8794053&contentNo=1)、
  [神戸大学「株式公開買付（TOB）における買収プレミアム」](https://da.lib.kobe-u.ac.jp/da/kernel/0100482447/0100482447.pdf)、
  [マネーフォワードクラウド「TOBで株はどうなる？」](https://biz.moneyforward.com/ma/basic/85/)

### 3-3. 自己株式取得（自社株買い）
- 通説: 流通株式数の減少により需給がタイトになり、**株価の上昇要因**として扱われることが多い。
- 「企業自身が自社株を割安と判断している」というシグナリング効果が働くとされる。
- ただし「必ず上昇するとは限らず、市場全体の地合いや財務状況にも左右される」という留保が併記されるのが通例。
  出典: [松井証券マネーサテライト](https://www.matsui.co.jp/money-satellite/column/beginner/stock/cl-own-stock.html)、
  [マネーフォワードクラウド「自社株買いとは」](https://biz.moneyforward.com/ma/basic/589/)

### 3-4. 増資（第三者割当・公募・発行登録）
- 通説: 発行済株式数の増加により1株当たり価値（EPS等）が希薄化し、**株価の下落要因**として扱われることが多い
  （「悪材料」と受け止められやすい）。
- ただし「増資目的が前向き（成長投資など）で、既存株主にとってもメリットが大きいと市場が判断した場合は
  株価が上昇するケースもある」という留保も一般的に付される。
  出典: [SMBC日興証券 用語集「希薄化」](https://www.smbcnikko.co.jp/terms/japan/ki/J0718.html)、
  [投資のコンシェルジュ「株式の希薄化とは」](https://www.invest-concierge.com/posts/understanding-stock-dilution-and-its-impact-on-shareholders)

### 3-5. 株式分割
- 通説: 1株当たりの投資単位が引き下がり、個人投資家が買いやすくなることで**需要（買い手の裾野）が広がる**
  効果が期待されるとされる。
  出典: [野村ウェルスタイル「株式分割発表後、株価はどう動く？」](https://www.nomura.co.jp/wealthstyle/article/0792/)

**→ 実務上の含意**: EDINET由来の開示イベント（大量保有・公開買付関連の開示等）を株価と突き合わせる際、
「一般的にこう解釈される」という**方向感（需給にプラス／マイナス／中立）を定型的なタグとして持たせ**、
それを「事実の解釈」として明示しつつ「個別銘柄でそうなる保証はない」という留保を必ず併記する設計が妥当。

## 4. 会社予想が手に入らない制約下での実績ベース分析

- 通説的な時系列分析の型として、**前年同期比（YoY）比較**は季節性のある事業の季節要因を自然に除去し、
  真の成長トレンドを把握する手法として広く紹介されている。
  出典: [Cryptul Insights「時系列分析の基礎」](https://cryptul.co.jp/insights/articles/097-time-series-analysis-fundamentals)、
  [田崎会計事務所「損益計算書は前年同期比で比較する」](https://tasaki-ac.jp/column13.html)
- 時系列データを「トレンド・季節性・残差」に分解し、移動平均で短期ノイズを均してから水準を評価する、という
  一般的な手法（STL分解等）が紹介されている。
  出典: 同上、[和から「移動平均のチカラ」](https://wakara.co.jp/mathlog/20251111)
- **複数年（例: 過去3〜5期）のレンジで確認することが重要**という指摘も一般的。

**→ 実務上の含意（TDnet・会社予想が無い制約への対応）**:
- 有報・半期報の実績数値について、**前年同期比・前期比のトレンド**、**過去数期のレンジ内での位置**、
  という「予想と比較しない」実績ベースの言い方に限定するのが、データの裏付けと矛盾しない書き方になる。
- 「会社予想に対する進捗率」のような、手元にないデータを前提にした言い回しをAIに書かせない
  （プロンプト・スキーマ双方でガードする）べき。

## 5. 同業比較ができない制約下での代替（自己ヒストリカル比較）

- 通説: バリュエーション評価で同業他社比較ができない場合、**その銘柄自身の過去のPER・PBR等の推移
  （ヒストリカル・マルチプル）と現在値を比較する**手法が代替として広く使われる。
  出典: [株探サポート「ヒストリカルPER」](https://support.kabutan.jp/hc/ja/articles/16247496116377)、
  [Co-A-Rising「業界ごとのバリュエーションの差異」](https://www.co-a-rising.com/valuation-by-industry/)
- 「PBRの水準だけでなく、なぜ高い／低いのかという要因分析、PERやROEなど複数指標を併せて総合的に検討する」
  ことが望ましいとされる（単一指標への依存を避ける）。
  出典: [AGSコンサルティング「PBRとは」](https://www.agsc.co.jp/ags-media/18694/)
- 分析期間としては**5年程度のレンジ**を採る例が一般的（業界レポートの手法例）。
  出典: [Co-A-Rising](https://www.co-a-rising.com/valuation-by-industry/)

**→ 実務上の含意**: 「同業他社比較ができない」制約は、**自己ヒストリカルレンジ（過去5年程度）内での
現在位置を示す**ことで一定程度緩和できる。ただし「業界水準に対して割安／割高か」は原理的に言えないため、
AIの出力では**「自社の過去レンジに対して」という限定を必ず明示させる**必要がある。
また単一指標（PERだけ等）で結論を出さず、**複数指標の整合性**（例: PER低いのにPBRも低い＝低ROEが原因、等）
を確認させる設計が望ましい。

## 6. リスク要因の類型

### 6-1. CFA協会準拠の実務解説
- リスク要因の節は「投資テーゼに対する潜在的なマイナス材料」を扱う場所とされ、
  「オペレーショナル」「財務」「規制・法的手続き」に大別されると説明される。
  出典: [AnalystPrep – Elements of a Company Research Report](https://analystprep.com/cfa-level-1-exam/equity/elements-of-company-research-report/)
- 一般的な金融リスク分類として「市場リスク・信用リスク・オペレーショナルリスク・流動性リスク・法務／規制リスク」
  という古典的な5分類が言及される。
  出典: 検索結果より（CFA Institute関連文献の要約。個別URLの本文確認はできず、分類名の一般性は他の複数の
  金融教育資料とも整合）

### 6-2. 日本の有価証券報告書「事業等のリスク」の記載実務（金融庁）
- 金融庁は「事業等のリスク」として、**業績の異常な変動、特定の取引先・製品・技術への依存、
  特有の法的規制・取引慣行・経営方針、重要な訴訟の発生、役員・大株主・関係会社に関する重要事項**などを
  例示している。
  出典: [日本証券業協会 藤林論文（事業等のリスクの記載範囲）](https://www.jsda.or.jp/about/kaigi/chousa/JCMF/JSDA_Fujibayashi2.pdf)
- 開示にあたっては、各リスクについて**発生可能性・影響度・前年からの重要性の変化・経営方針との関連**を
  併記することが望ましいとされる（金融庁「記述情報の開示の好事例集」の趣旨）。
  出典: [金融庁「事業等のリスクの開示」](https://www.fsa.go.jp/news/r2/singi/20210416/03.pdf)（PDF構造上、本文の詳細抽出は不可。
  タイトル・関連解説記事から趣旨を確認）、[東京海上ディーアール解説記事](https://www.tokio-dr.jp/publication/report/riskmanagement/riskmanagement-226.html)

### 6-3. 整理（本ツールで採用しうる分類）
以上を踏まえ、一般的な実務解説とEDINET実務の双方に整合する形で、以下の6分類が妥当と考えられる
（これは調査者による整理であり、単一の公式文献がこの6分類をそのまま提示しているわけではない）:

1. **業績リスク**（需要変動、特定取引先・製品への依存、コスト変動）
2. **財務リスク**（資金調達、キャッシュフロー、格付、負債水準）
3. **バリュエーションリスク**（自己ヒストリカルレンジからの乖離、市場心理の反転）
4. **イベントリスク**（大量保有・TOB不成立・増資・訴訟等、開示された個別事象）
5. **流動性リスク**（出来高の薄さ、値幅制限、大口保有の偏り）
6. **ガバナンスリスク**（大株主・役員関連の重要事項、内部統制、開示の質）

## 7. AIに分析させる際の「やらせてはいけないこと」

### 7-1. 投資助言業の該当性（一般的な説明。個別の法的判断ではない）
- 金融商品取引法上、投資助言業は「有価証券の価値等の分析に基づく投資判断について、対価を得て助言を行う」
  行為として定義される。
  出典: [金融庁 監督指針 VII](https://www.fsa.go.jp/common/law/guide/kinyushohin/07.html)、
  [牛島総合法律事務所「投資助言業登録が必要となるか否か」](https://www.ushijima-law.gr.jp/topics/20250421investment_advisory/)
- 一般的な整理として、**「景気動向・特定企業の業績・株価の基礎資料の分析など一般的知識の提供」は
  投資助言業に該当しないが、「特定企業の株価・利益の予測」を行うと該当しうる**、という線引きが
  複数の実務解説で共通して示されている。
  出典: [サポート行政書士法人「投資助言業に該当しないケース」](https://www.shigyo.co.jp/search_post/kinyu/toushijyogen/jyogen_kaitousinai/)、
  [IT弁護士 中野秀俊「投資助言業に該当する・しないの判断基準」](https://it-bengosi.com/blog/toshi-jogen-sakaime/)
- 分析ソフトウェアの販売について、**「誰でもいつでも自由に購入できる状態」であれば投資助言業には
  該当しないが、販売業者が継続的に個別の投資情報・サポートを提供する場合は該当しうる**、という整理も
  紹介されている。本ツールはローカル動作かつ単一ユーザー向けであり、この論点は限定的だが、
  **「継続的に個別銘柄について断定的な売買推奨を行う」運用にしないことが安全側**と言える。
  出典: 同上
- AIが助言を生成する場合でも、**法的責任やユーザーへの説明責任はサービス提供者（人間側）に帰属する**、
  という考え方が紹介されている。
  出典: [日本銀行金融研究所「投資判断におけるアルゴリズム・AIの利用と法的責任」](https://www.imes.boj.or.jp/research/papers/japanese/kk38-2-1.pdf)

### 7-2. 実務上の一般的な線引き（本調査のまとめ。個別の法的助言ではない）
- **してよいとされやすい**: 過去の実績・指標の記述、開示事実の要約、「一般的にはこう解釈される」という
  市場の通説の紹介、複数のシナリオの併記（上振れ・下振れ材料の列挙）
- **避けるべきとされやすい**: 「買い」「売り」等の断定的な売買推奨、具体的な目標株価・期待リターンの提示、
  「今が買い時／売り時」という断定的なタイミング判断、将来の企業業績・利益の断定的予測
- **免責表示の一般的な書き方の例**（複数の情報サイトで共通のパターン）:
  「本レポートは情報提供を目的とするものであり、特定の銘柄の売買を推奨し、または投資の勧誘を行うものではない。
  記載内容の正確性・完全性を保証するものではなく、投資判断は利用者自身の責任で行うこと。」
  出典: [株探ニュース関連免責例](https://kabutan.jp/news/marketnews/?b=n202512120366)、
  一般的な個人ブログ・ツールの免責表記事例（複数ソースの共通パターンとして整理）

**→ 実務上の含意**: 現行スキーマの `verdict`（強気・弱気・中立）は、文言次第で「推奨」と受け取られる
リスクがある。**`verdict` は「市場評価の方向性の要約」であって「売買推奨ではない」ことをプロンプト・
UI双方で明示**し、断定的な目標株価・期待リターンの数値をAIに生成させない設計を維持すべき。

## 8. 出力スキーマへの提案（詳細は末尾「改訂案」参照）

- **`fundamental` セクションの新設**: 有報・半期報の実績数値を根拠に、業績トレンド（YoY）・
  自己ヒストリカルバリュエーションレンジ内の位置を評価する場所を作る。ただし「会社予想との比較」は
  データがないため明示的に書かせない（プロンプトで禁止する）。
- **根拠の出典の明示**: 各評価項目に「どのデータ（OHLCV／指標名／開示書類名・提出日／財務諸表の科目）を
  見たか」を機械可読な形で残すフィールドを追加し、レポート内でも根拠元を示せるようにする。
- **矛盾点の明示**: `technical` と `fundamental` の評価が一致しない場合に、それを「時間軸のズレ」として
  言語化させるフィールド（`consistency_note` 等）を追加する。
- **イベントの解釈と留保をセットにする**: 開示イベントを扱う際、「一般的な解釈（方向感）」と
  「個別にそうなる保証はないという留保」を1組のフィールドにする。

# 最終報告（サマリー）

## A. 推奨する分析の型（このツールの制約下で現実的なもの）

- **投資テーゼ中心の統合型**にする。`technical`/`disclosure`/`fundamental` を並列列挙するのではなく、
  「何が株価評価の背骨か（投資テーゼ）→それを支える材料／崩す材料」という構造にする
  （CFA協会準拠の実務解説にある「投資テーゼ→検証材料→リスク」の順序を踏襲）。
- **時間軸を分離する**: テクニカル（短期の需給・心理）とファンダメンタル（中長期の実績トレンド）を
  「矛盾」ではなく「時間軸のズレ」として扱い、両者が一致しているかを明示的に評価する
  （通説の「銘柄選択はファンダ、タイミングはテクニカル」を踏まえる）。
- **実績ベース・自己ヒストリカル基準に徹する**: 会社予想が無いため「予想比」を語らせず、
  前年同期比・複数期のトレンド・自社の過去レンジ内での位置づけ、に限定する。
- **イベントは「事実の解釈」として定型的に扱う**: 大量保有・TOB・増資・自社株買い・株式分割など、
  一般的にどう解釈されるかを定型タグ＋留保文で処理し、個別の株価予測に接続しない。
- **リスクは類型別に網羅性チェックする**: 業績・財務・バリュエーション・イベント・流動性・ガバナンスの
  6類型を毎回チェックリストとして通し、該当するものだけを書かせる（漏れの検出に使う）。
- **断定を避け、通説と限界を必ず併記する**: 「一般的にはこう解釈される」「本ツールが参照できるデータの
  範囲では」という限定を、評価系のフィールドすべてに構造的に持たせる。

## B. 出力スキーマの改訂案（現行→改訂の差分）

現行: `technical`（根拠→評価）/ `disclosure`（根拠→評価）/ `risks` / `watch_points` / `verdict` / `confidence` / `summary`

改訂案:

| フィールド | 型 | 説明 | 現行との関係 |
|---|---|---|---|
| `thesis` | string | 「何が今の株価評価の背骨か」を1〜3文で。個別の売買推奨語を含めない | **新規**。全体の要約を`summary`から独立させ、根拠より先に置く上位概念 |
| `technical` | { basis: string[], evaluation: string } | テクニカル指標のうちどれを見たかの明示＋評価。現行と同様だが `basis` を配列化し出典を機械可読に | 既存を拡張（根拠の構造化） |
| `fundamental` | { basis: string[], trend: string, historical_valuation: string, evaluation: string } | 有報・半期報の実績数値。`trend`は前年同期比・複数期推移、`historical_valuation`は自己ヒストリカルレンジ内の位置。**会社予想との比較は書かせない**（プロンプトで明示的に禁止） | **新規**。現行スキーマに存在しなかった財務ファンダメンタル評価 |
| `disclosure` | { basis: string[], evaluation: string } | EDINET開示（有報・半期報以外の適時開示相当も含む）。現行と同様だが根拠を構造化 | 既存を拡張 |
| `event_reads` | [{ event: string, filing_date: string, general_interpretation: string, caveat: string }] | 大量保有・TOB等のイベントごとに「一般的な解釈（方向感）」と「個別に当てはまる保証はないという留保」を1組で記録 | **新規**。`disclosure`から独立させ、通説の解釈と留保をセットで強制する |
| `consistency` | { aligned: bool, note: string } | テクニカルとファンダメンタルの評価が一致するか。不一致なら時間軸のズレとして言語化 | **新規** |
| `risks` | [{ category: "業績"\|"財務"\|"バリュエーション"\|"イベント"\|"流動性"\|"ガバナンス", description: string }] | 6類型のタグ付けを必須化。該当なしの類型は出力しない | 既存を拡張（分類必須化） |
| `watch_points` | string[] | 現行維持。次に見るべき指標・開示 | 変更なし |
| `verdict` | "強気"\|"弱気"\|"中立" | 現行維持。ただしプロンプトとUI双方で「市場評価の方向性の要約であり売買推奨ではない」と明示する運用を追加 | 変更なし（運用上の注記を追加） |
| `confidence` | "低"\|"中"\|"高" | 現行維持。ただし「同業比較不可・会社予想無し」という構造的制約がある場合は`confidence`を機械的に「高」にできないようプロンプトでガードする案を推奨 | 変更なし（運用ガード追加） |
| `summary` | string | 現行維持。`thesis`の新設により、`summary`は結論の平易な言い換えに役割を絞る | 役割の再定義 |
| `data_scope_note` | string | 「本レポートが参照したデータの範囲（会社予想なし・同業比較なし・需給データ不使用）」を毎回定型文で明示 | **新規**。免責と透明性を兼ねる |

## C. 制約のうち、分析の質に最も効いてしまうもの

**最も効くのは「会社予想（TDnet）が手に入らないこと」と考えられる。**

理由:
- セルサイド実務の標準構成（CFA協会準拠の解説）でも「業績予想」「目標株価とその前提」がレポートの中核に
  位置づけられており、実績と予想の**乖離（サプライズ）こそが株価を動かす主因**という位置づけが強い
  （出典: [Wall Street Prep](https://www.wallstreetprep.com/knowledge/sample-equity-research-report/) 等の実務解説）。
  これが欠けると、分析は「何が起きたか」は語れても「市場の期待に対してどうだったか」を語れず、
  株価変動の説明力が構造的に落ちる。
- 一方、「同業比較不可」は**自己ヒストリカル比較で相当程度代替可能**（§5参照）であり、
  「需給データをAIに送らない」制約は、AIの分析範囲を明確に絞る設計上の制約であって、
  データの入手可否の問題ではない（そもそも規約上の不変条件であり、緩和すべき対象ではない）。

**緩和策の提案**:
- 「会社予想が無い」ことを埋め合わせるのではなく、**構造的に諦めて明示する**のが最も安全な設計。
  具体的には、`fundamental.trend` を「予想比」ではなく「前年同期比・自己ヒストリカルトレンド」に
  限定し、`data_scope_note` で「本ツールは会社側の業績予想を参照していないため、市場コンセンサスとの
  乖離（サプライズ）は評価対象外」と毎回明記する。
- 将来的に緩和したい場合の現実的な代替は、**東証・会社が適時開示する「業績予想の修正」自体はTDnetだが
  取得しない前提のため対象外**、あるいは有報・半期報に記載される**前期の会社発表予想と実績の比較
  （事後開示されている範囲）**を使う方法があるが、これは新たなデータソースの追加検討が必要であり、
  本調査のスコープ外（別タスクとして切り出すべき）。
